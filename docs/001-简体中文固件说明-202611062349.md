# WLED 16.0.1-zh-CN.1 简体中文固件

基于上游正式版 `v16.0.1`，汉化版本 `16.0.1-zh-CN.1`。源码及在线编译仅位于 `jiangmo/WLED` 的 `zh-cn-16.0.1` 分支，不向上游推送。

## 修改范围

- 主控制界面、预设与播放列表、分段、设备信息及提示。
- WiFi、LED 硬件、二维矩阵、同步、时间宏、界面、安全、用户模块及引脚设置。
- 欢迎页、升级页、文件编辑器、实时预览、调色板编辑器、内置图片工具及错误页面。
- 全部内置灯效、调色板名称及灯效参数在显示层翻译，保留原 API 元数据、编号、配置键和用户自定义名称。
- 固件返回的设置保存、重启、PIN 验证、OTA 校验及相关错误提示。
- 页面统一声明 `zh-CN` 和 UTF-8；扩大中文保存提示、Hue 状态及日出日落文字缓冲区。
- 修复简化界面原有 ASCII 过滤器会删除中文名称的问题。

品牌、芯片和协议名称、GPIO、RGB、物理单位、网址及代码示例保留原表示。用户自建文本、外部下载的工具/调色板和第三方浏览器编辑器自身的界面由其提供方决定。未启用的社区用户模块不包含在本次通用固件内。

## 在线编译

GitHub Actions 工作流：`.github/workflows/zh-cn.yml`。向汉化分支推送会构建 `nodemcuv2` 与 `esp32dev`；也支持手动触发。运行 `npm test`、打包网页后再由 PlatformIO 编译固件。产物包括二进制、SHA-256 校验和与本说明，Actions 保留 90 天。

本地不运行单片机编译；本次编译按用户明确要求在 GitHub Actions 中执行。

## 固件选择与刷写

| 文件 | 适用设备 | 用途与地址 |
|---|---|---|
| `WLED_16.0.1-zh-CN.1_ESP8266.bin` | 通用 ESP8266，4 MB 闪存，NodeMCU/D1 mini 类开发板 | 串口刷写地址 `0x0`，或从已有 WLED 的更新页面上传 |
| `WLED_16.0.1-zh-CN.1_ESP8266.bin.gz` | 同上 | 压缩 OTA 更新，适合可用 OTA 空间不足时 |
| `WLED_16.0.1-zh-CN.1_ESP32.bin` | 经典 ESP32，4 MB 闪存，ESP32-WROOM/DevKit 类开发板 | 已有 WLED 的 OTA 更新；属于应用镜像，不能单独作为 `0x0` 首刷文件 |
| `WLED_16.0.1-zh-CN.1_ESP32_factory.bin` | 同上 | 首次串口刷写的合并镜像，地址 `0x0`，含引导程序、分区表、OTA 初始化数据和应用 |

ESP32-C3、S2、S3 等芯片不可使用经典 ESP32 镜像。ESP8266 1 MB/2 MB 设备需使用专用构建配置。

升级前在“安全与更新”中备份配置和预设。整片擦除会清除配置；先备份，再按是否需要保留数据选择操作。OTA 页面上传常规 `.bin`，不要上传 `_factory.bin`。刷写后连接 `WLED-AP` 配置 WiFi，或继续使用原来的设备地址。若浏览器显示旧页面，请刷新或清除缓存。

## 检查与限制

`tools/zh-cn-test.js` 对照上游选择器、事件及存储键指纹，检查所有内置灯效、参数及调色板的中文覆盖，验证简化界面保留中文、页面编码和 JavaScript 语法。上游网页打包测试同时保留。

编译通过说明目标配置可生成固件；尚未连接实物进行刷写、灯带输出、网络或 OTA 往返验证。设备实际引脚、电源与 LED 参数仍需按硬件设置。
